# Week 4 - CIFAR-10 Image Classification

## Assignment
Build an image classification model on CIFAR-10 and analyze performance across architectures and training strategies using both ANN and CNN.

## Topics Covered
- CIFAR-10 Dataset
- Artificial Neural Network (ANN)
- Convolutional Neural Network (CNN)
- Batch Normalization
- Dropout
- Data Augmentation
- Early Stopping
- Model Performance Comparison
- Confusion Matrix
