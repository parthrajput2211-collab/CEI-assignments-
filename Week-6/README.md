# Week 6 - Image Denoising using Autoencoder

## Assignment
Build a deep learning autoencoder model to remove noise from MNIST images.

## Topics Covered
- MNIST dataset
- Image noise generation
- Autoencoders
- Encoder and Decoder
- Fully Connected Autoencoder
- Convolutional Autoencoder
- Transposed Convolution
- Upsampling
- Image reconstruction
- Image denoising
- MSE-based evaluation
